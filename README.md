### 💡 Cómo trabajo

- **Primero el problema del negocio:** construyo lo que el cliente necesita, sin funciones de adorno.
- **Las reglas importantes viven en el servidor:** precios, permisos y estados se validan allí, nunca solo en el navegador.
- **Seguridad desde el inicio:** contraseñas con hash, sesiones seguras, control por roles y protección CSRF.
- **Código que se puede mantener:** pruebas automáticas, CI y documentación clara.
